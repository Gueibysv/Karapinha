# Karapinha – Salon Booking System

💇‍♂️ Web application developed for the **Web Applications** course at **ISPTEC**, aimed at managing **appointments for a beauty salon**.

The project provides a complete solution for client bookings, service management, and appointment scheduling, applying modern **web development practices**.

---

## 📌 Project Overview
**Karapinha** is a web-based booking system designed to simplify the process of scheduling appointments in a beauty salon.

The application allows clients to request appointments online, while administrators can manage services, schedules, and bookings efficiently.

This project was developed as an **academic project**, focusing on both frontend and backend integration.

---

## 🎯 Objectives
- Develop a full-stack web application  
- Apply client–server architecture concepts  
- Implement a booking system for a beauty salon  
- Integrate frontend and backend using RESTful APIs  
- Consolidate knowledge acquired in Web Applications  

---

## 🛠️ Technologies Used
### Frontend

- HTML, CSS, TypeScript  

### Backend
- **ASP.NET Core (C#)**  
- RESTful Web API  

### Database
- SQL Server  

---

## ⚙️ Main Features
- Online appointment booking  
- Client management  
- Service and schedule management  
- Admin panel for booking control  
- REST API integration between frontend and backend  

---

## 🧱 System Architecture
The system follows a **client–server architecture**, with:
- Angular handling the user interface  
- ASP.NET Core providing business logic and APIs  
- Database layer for persistent data storage  

This structure ensures **scalability, maintainability, and clear separation of concerns**.
